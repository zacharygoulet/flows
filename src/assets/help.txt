The `flow` tool helps AI agents follow configured, deterministic flows. It tracks
progress; the agent does the work.

A flow describes steps, their guidance, and normal next transitions. Start an
instance from a flow, use show to read its current guidance, move with next,
or use jump for exceptional moves. Use 'flow route' for optional
instance-specific initial, final, and skipped steps.

Guidance at global, flow, and step levels can include a checklist of instructions.
Checklist items are not individually tracked. Use 'flow list steps <flow-name>'
to list a flow's steps.

Instances can be assigned autonomy level per step, per-instance context, and an
optional informational owner. Ownership does not block operations.

Context is a persistent set of compact reminders or pointers for later steps, such as
an issue ID or plan URL. Values are limited to 150 characters; keep detailed plans,
requirements, and notes in their proper documents instead.

Each [[steps]] entry can set autonomy = "guided", "steered", or "autonomous";
omitted values default to guided. Guided autonomy confirms step boundaries
and each emerging design choice. Steered autonomy proceeds with routine work and
asks on consequential choices. Autonomous autonomy works independently
and escalates fundamental blockers or reserved decisions.
New instances save these defaults per step. Loading older instances fills only
missing autonomy entries from the flow defaults; saved values are preserved even
if the flow defaults change. Override saved levels with 'flow autonomy set'.

Use 'flow list instances' to see available instances
Use 'flow start <...>' to start a new instance
Use 'flow claim <instance> --owner <owner>' to claim an unowned instance
Use 'flow help' for all commands.
Use 'flow help <command>' for a command's arguments and options.

Use 'flow list flows' for flows; bare 'flow list' shows help.
Use 'flow show <instance> --step <step>' to preview without moving.
Omitted next targets require exactly one effective destination; otherwise choose explicitly.
Route initial set configures only; 'flow reset <instance>' moves to the configured initial step.
Use 'flow autonomy set <instance> <level> --step <step>' or '--from <first> --through <last>'.
Ranges follow the original flow graph, ignoring route overrides.
Storage is .flow locally and $XDG_STATE_HOME/flow globally (default ~/.local/state/flow).
No aliases, old-path fallback, or automatic migration are provided.
